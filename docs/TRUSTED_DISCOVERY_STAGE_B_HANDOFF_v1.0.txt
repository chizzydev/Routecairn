Witness guarantee and explicit limits
Independent witness directory must be canonical and outside ordinary dataDir.
It contains a protected stable key and FULL-synchronous signed contiguous append
chain, immutable attempt/outcome rows, capacity4096, backing-file identity and
bounded8MiB validation. Main DB checkpoint binds original main canonical path,
installation, Stage A stable namespace, fixture origin and independent witness
path. Key custody, exact rows and checkpoint are rechecked after asynchronous
waits and at the actual synchronous initiation boundary, including Date.now
after bounded synchronous IO.

Witness commits first. Process death or main-transaction rollback can leave an
unmatched witness record: every subsequent native open or transition refuses.
Main ahead, key missing/rotated, namespace missing, file replacement/corruption,
chain truncation, partial write, copied main path or SQLite/witness busy also
refuse. No automatic reconciliation lowers history. Interrupted provisioning
can only be investigated under a separately reviewed recovery procedure.

Outcome integrity repair addendum v1.0
Individually signed present rows were insufficient to detect deletion. Outcome
custody now requires an ordered signed ledger AND separately authenticated main
high-water binding/count/tip. Required guards and both commitments are checked;
deleting data and restoring SQL guards does not conceal a missing committed row.
Witness outcome commits before main checkpoint, and any mismatch refuses native
authority. Attempts without an outcome are unknown, permanently spent, never
successful proof. Actual post-response storage failure preserves native counters
and reports inconclusive; partial commits are never healed or refunded.
Reconciliation is bounded and uses indexed O(n) maps, not quadratic scans.
Old custody without v2 outcome commitment is refused, never automatically reset.
See TRUSTED_DISCOVERY_OUTCOME_INTEGRITY_v1.0.txt for the complete crash matrix,
paired-history rollback limitation, retained Stage C/D and owner-review gates.

Platform and evidence boundaries
All fixtures are new private user-temp directories, loopback listeners and
self-maintained retained reports/accounts. Test-only IPC acknowledges metadata;
raw passwords/cookies/keys/receipts are not delivered. TLS keys stay memory-only.
Browser uses real installed headless Chromium and scoped self-signed fixture TLS
without OS trust-store edits. Proxy permits only active loopback UI origins,
checks actual connected peers and denies other destinations before DNS/upstream.
Traces are disabled because auth traces include credentials. Only terminal,
review-cleared screenshots/DOM summaries are exported; private markers checked.
Screen-reader/OS accessibility behavior is NOT VERIFIED by DOM aria assertions.
Windows ACL/mount policy and real Ubuntu native acceptance remain owner gates.
POSIX permission assertions only run on actual Linux; no platform mock/shim.
Unsupported symbolic link creation is BLOCKED, not a skipped or passed capability.
The original junction and64-context30s tests remain mandatory, unchanged.

Build/release inspection and source conflict
Normal build/typecheck/UI-build/lint/format/1800-line architecture, lock and
version/package-input checks are scoped; preserve captured stdout/stderr/exits.
Dry-run npm packing uses --ignore-scripts: no lifecycle, install or publishing.
package:smoke invokes npm install, therefore BLOCKED under this contract.
build:release clears verified generated dist; BLOCKED here pending reviewed
preservation/isolation of existing generated outputs. No old evidence deletion.
React bundles must exclude fixture bootstraps/key material/execute adapters.
The frozen NODE package contains the internal OperatorService.executeFresh
implementation, as required by existing shipping server imports. No witness
bootstrap/bridge/HTTP route is shipped. A literal requirement to remove that
internal implementation conflicts with preserving frozen consensus; retain and
flag this distinction for independent review, never delete it to force a pass.
Policy/version readiness is not independent release/security signoff.

Open Application Authorization → guided mapping. Start with approved explicit seed routes and saved target-bound credentials. ## Limits and supported discovery

Only passive JSON objects with href and optional explicit GET method, or HTML anchors, from already-approved native successful responses. HTML base overrides, cross-origin/userinfo/query/fragment/percent/backslash/control/traversal/obvious destructive paths are excluded. Returned links never grant safe-GET authority. Unsupported content, truncation, cap exhaustion, missing actor proof or expired review is explicit. Three reviewed rounds per lineage; 8 suggestions/36 request cap per round; source freshness30m, review10m; each approval is one-time. Deliberately starting a new source lineage is a new manual approval, not a global crawler quota. No query-pagination, arbitrary JavaScript execution, automatic OpenAPI fetch, link following or mutation. Existing reviewed OpenAPI import remains available.

## Evidence and measurement

Every selection binds an immutable scoped proposal and native report SHA. Native plan admission revalidates source, target, credentials, scope, expiry, exact candidate selection and budget. Missing dispatch acknowledgements retain existing UNKNOWN/no-replay semantics and quarantine. Proposed/actual route coverage is separate from source completeness and observed authorization.

The test-only frozen oracle defines ArchiveHub principal/role/tenant/resource policy before observations; the product does not import it. Native predictions are saved before scoring. The scorer validates exact unique IDs and separately counts TP/FP/TN/FN, correct/unsafe abstention, untested cases, selective false-positive denominator coverage, conservative recall and null undefined metrics. Label authenticity is external to the scorer. Current evidence is local, self-maintained and unblinded; it does not fulfill independently maintained blind corpus or owner-run product acceptance.

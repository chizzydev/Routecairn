## Evaluation and interpretation

HeldOutDiscoveryEvaluation reuses the existing application scorer and canonical corpus serialization. Strict contracts bind oracle bytes, product sources, per-app case IDs, eligible route/source denominators and request ceilings. Prediction receipts are retained before label reveal by the owned evaluation harness. Duplicate/extraneous cases, changed commitments, inflated coverage or over-budget measurements are refused. Missing predictions remain untested; known-truth abstention is not a true negative. Metrics include the false-positive denominator and conclusive fraction, plus per-app wall cost and parent-process CPU explicitly excluding worker CPU. Neutral always-abstain results remain visible.

No independently authored oracle was supplied. The provided ledger, clinic and helpdesk models are **SELF_MAINTAINED_HELD_OUT**, unblinded; models/policies are known to authors. Label JSON is distinct from application implementations, scoring and product input. Operator policy declarations are required input and are not autonomous detector inference. The first-attempt failures and disclosed fixture-corrected reruns are included. Do not treat reruns as an untouched independent test split or pool narrow models into a generalized accuracy claim.

See the current review ZIP TEST_MATRIX, raw prediction/label/score files, predeclaration, native SQLite/wire/worker receipts, failed attempts and actual Edge screenshots for results. No old passing number is a current result.
